# VisualWordProblem

VisualWordProblem is a small static web project that presents visual word problems using ocean-themed assets.

Contents
- `index.html` — main page
- `Ocean_Friends/` — image assets used by the page
- `Background.png` — background image

Quick start
1. Open `index.html` in a browser (double-click or serve it).

Serve locally (optional):

```bash
cd /Users/maytinee/Git_Whale/whale/VisualWordProblem
python3 -m http.server 8000
# then open http://localhost:8000
```
